How this index is built

Built on every weekday refresh by a script that reads the same structures the research pages are rendered from, never a hand-typed list. An item whose link or anchor no longer resolves is left out and the refresh log says so; the site's rule check then confirms every published research page is listed. Private ledgers appear as counts only. Research and education, not investment advice; backtests are hypothetical.
